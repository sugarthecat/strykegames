Claims

A game theory tournament.

● Encroach bot 1 Turn 1 Random bot 1 ●

Encroach claims a vertex as close as possible to its opponent. Random claims a random vertex.

Game Rules

  1. The game begins with a connected graph, and each participant having at least one vertex marked as theirs in the connected graph. As part of the initial conditions, one player is chosen to go first.
  2. For each turn, the player sees the graph, and may select an unclaimed vertex adjacent to one of their claimed vertices, and claim it. If an invalid move is made, or no moves are possible, the player skips their turn.
  3. The game ends when both participants skip their turn.

Scoring

  1. There is a set of initial conditions that will be used to evaluate your bot.
  2. Every bot submitted will compete against every other bot submitted, plus a few reference bots.
  3. For each pair of bots, and graph, the bot's score for the round is its number of claimed vertices.
  4. The initial conditions may be asymmetric. To make this fair, any asymmetric board will be evaluated for each orientation.
  5. Bots, in the end, will be ranked based on their total score across rounds.
  6. The collection of graphs for scoring will be curated, both for graphs representing interesting real-world phenomena, but also for graphs which test important claimer properties.

Submission Guidelines

  1. There will be no more than 1,000 vertices in each graph.
  2. If a bot's total computing time for a single game exceeds 30 seconds, or crashes, any future moves by the bot in the game will be made by the Random bot.
  3. Only one submission is allowed per person.
  4. Standard Python libraries are allowed.
  5. Bots will be re-initialized for each game.
  6. Bots will be run in python3.

Submission Format

A Python class named GraphClaimer. It gets the graph and both sides' starting vertices once, is told each vertex the enemy claims, and returns the vertex it wants to claim next.
